## 4. Known Blockers / Out-of-Scope Items

- **Header Relative Paths:** `partials/header.html` contains links like `../../index.html` and `../../support/docs.html`. From depth 3 (`pages/admin/<slug>/<slug>.html`), these resolve to non-existent `/pages/index.html`. Per Rule 3, `partials/header.html` is strictly protected and was NOT modified.
- **Root Landing Page Link:** `index.html` has an "Open" button linking to `pages/admin/landing.html`. To ensure this link functions smoothly without editing the protected `index.html`, a redirect shim `pages/admin/landing.html` was created to route directly to `pages/admin/platform-admin-home/platform-admin-home.html`.

## 5. Next Steps for Next Agent / Operator

1. Keep Live Server on port 5500 and FastAPI backend on port 8000 when performing interactive user testing.

3. If requested by the project lead, request permission to adjust relative links in `partials/header.html` to root-relative paths (`/index.html`, `/support/...`).

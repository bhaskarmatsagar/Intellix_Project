Prove it is live: change a value in MySQL

  1. Keep this page open with auto-refresh on.
  2. Open MySQL (Workbench, or the mysql prompt) and run the statement below.
  3. Within a few seconds the changed cells flash yellow here. Nothing was touched in the code.
USE edx_slo_monitoring;
UPDATE slo_definitions SET current_pct = 99.50, status = 'Breached' WHERE slo_id = 'SLO-API-SUCCESS-001';
-- Now "SLI reconciled" turns to NO, because 99.50 no longer matches the sample counts.
UPDATE measurement_snapshots SET successful_count = 999500 WHERE slo_id = 'SLO-API-SUCCESS-001';
-- sli_pct changes to 99.9500 automatically (MySQL computes it).
INSERT INTO reviewers (display_name) VALUES ('Test Reviewer');   -- row count for reviewers goes up
